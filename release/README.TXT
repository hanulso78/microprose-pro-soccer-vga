===============================================================================
  MICROPROSE PRO SOCCER  (1989, MicroProse / IBM 판 Designer Software)
  C 변환판 + VGA 256색 리마스터 + 애드립 음악/효과음     VGA REMASTER BY IN-HAK MIN
===============================================================================

[들어 있는 파일]
  SOCVGA.EXE    VGA 256색 리마스터 판 + 애드립 음악 + 효과음
  SOCCER.EXE    원본과 똑같이 동작하는 판 (원본을 역어셈블해 C 로 옮김, EGA 16색 그대로)
  SOCVGA.DAT    256색 그림 자료 (경기장 음영, 선수 입체감)   - SOCVGA.EXE 에 필요
  SOUND.DAT     애드립 음악 16곡 + 효과음 (함성, 차기, 휘슬)  - SOCVGA.EXE 에 필요
  CWSDPMI.EXE   32비트 도스 실행 도우미 - 두 판 모두 필요
  IPITCH.BIN  ISPRITES.BIN  OPITCHC.BIN  OPITCHE.BIN  OSPRITES.BIN
                원판 자료 그대로 (경기장, 선수 그림) - 두 판 모두 필요

  모두 한 폴더에 두고 실행한다.

[실행]
  도스 또는 DOSBox 에서
      SOCVGA          256색 + 음악 판 (처음에 1) 실내  2) 실외 를 고른다)
      SOCVGA 1        실내 경기 (SIX-A-SIDE, 인도어 리그 ...) 로 바로
      SOCVGA 2        실외 경기 (월드컵, 국가 대항전 ...) 로 바로
      SOCCER          원본 그대로의 판 (같은 방법)
  VGA 그래픽 카드가 필요하다 (DOSBox 기본 설정이면 된다).
  처음 실행하면 조이스틱이 몇 개인지 묻는다 - 자판만 쓰면 0 을 고른다.

[조작]
  1P  W E R / S F / X C V  (여덟 방향),  Space = 차기
  2P  숫자판 1..9 (여덟 방향),           Enter = 차기
  P = 잠깐 멈춤      Esc (주 메뉴에서) = 게임 끝
  Ctrl+Q = 언제든 처음 고르기 화면으로

[소리]
  애드립 또는 사운드 블라스터가 있으면 원판의 PC 스피커 소리 대신
  애드립으로 편곡한 음악이 나온다 (멜로디 + 파워 코드 + 베이스 + 드럼).
  원판에 없던 효과음도 더했다:
    - 공을 찰 때 "퍽" (스로인으로 던질 때는 소리 없음)
    - 골: 심판 휘슬 + 관중 함성
    - 킥오프, 쿼터 끝, 코너킥/골킥, 실내 판정 (아웃, 3 라인 위반,
      골키퍼 시간 초과) 때 심판 휘슬
  함성, 휘슬, 크게 들리는 차기 소리는 사운드 블라스터의 디지털 소리라
  BLASTER 환경 변수가 있어야 한다 (DOSBox 는 저절로 있다).  없으면 애드립으로 대신한다.
  원판의 소리 끔 설정(게임 안 메뉴)을 따른다.

  환경 변수
      SET SOCNOSND=1    소리를 모두 끈다
      SET SOCSPK=1      애드립 대신 원판처럼 PC 스피커로
      SET SOCEGA=1      SOCVGA 를 원판 EGA 색으로

[256색 리마스터에서 바뀐 것]
  - 잔디는 깎은 줄무늬와 결, 선수는 입체감 있는 음영, 원판 유니폼 색을 살린 채색
  - 공 그림자는 잔디가 비쳐 보이게
  - 실외 경기의 가로 미세 스크롤을 원판대로 따라 배경이 선수와 함께 부드럽게 움직이고,
    원판이 숨겨 두던 좌우 가장자리 대신 경기장이 화면 폭을 채운다
  - 메뉴와 점수판 글자, 바탕을 새 색으로
  게임 진행(규칙, 선수 움직임, 점수)은 원판과 한 바이트도 다르지 않다.

[필요한 컴퓨터]
  486 + VGA.  486DX4-100 이상이면 제 속도로 돈다.
  486DX2-66 에서는 약 80% 빠르기 (게임이 조금 느려지고 화면을 건너뛴다).
  DOSBox 는 cycles=40000 이상 (또는 max) 을 권한다.

[만든 방법]
  원판 SOCCER.COM / OPITCH.BIN / IPITCHC.BIN 과 EGAIO.EXE 드라이버를 역어셈블해
  C 로 옮기고 (에뮬레이터로 돌린 원판과 폴마다 레지스터, 메모리, 화면을 대조해
  바이트 단위로 같음을 확인), EGA 화면을 흉내 내며 VGA 256색으로 다시 칠했다.
  음악은 원판의 소리 순서기를 돌려 뽑은 멜로디를 애드립용으로 편곡했고,
  함성, 휘슬, 차기 소리는 새로 합성했다.
